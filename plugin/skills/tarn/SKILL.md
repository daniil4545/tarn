---
name: tarn
description: Use when running inside the tarn terminal ($TARN_SURFACE is set) and a task needs a file shown to the user, a command run or watched in a pane next to you, a pane read or closed, or the user's attention.
---

Run `tarn skill` and follow the text it prints: the rules and commands of the tarn build you run in.

If the `tarn` command is missing, you are not in a tarn terminal: do nothing more with this skill.
