# Viewer pane

Canon for the keys, tabs, files tree, editor and disk-change behavior of the viewer pane (R5, R6, R9 of `docs/spec.md`); built. Placement of several viewers and drop zones: `docs/spec/workspaces.md` section 5. Swift holds all state; a WKWebView only draws it.

1. Purpose: read and edit a file next to a session without another app.
2. Input: a path from a click (`path`, `path:line`), `tarn open` or the files tree. Output: the file, rendered or as source.
3. How it works: the first open puts a pane to the right of the terminal area of a window tab; more viewers and their placement are in `docs/spec/workspaces.md`. Tabs: a file opens as a preview tab (italic) that the next open replaces; a double click, an edit or a drag pins it. A link to a text file keeps the document it leaves as a pinned tab and opens its target as the preview tab, so the next link from it replaces only the target (Zed's markdown preview, T-567). The files tree sits on the right of the pane, rooted at the terminal's cwd; the Files button toggles it inside the pane and Esc hides it. Cmd+B is the one pane key, from the terminal and from the pane; the Toggle File Viewer button in the sidebar header (and in the rail) does the same. With no pane, Cmd+B opens the pane with the tree only (rooted at the terminal's cwd, no file open) and puts the keyboard in the tree; a hidden pane comes back as it was hidden, with the keyboard in it. In a shown pane with a file, Cmd+B hides a visible tree or shows a hidden tree, keeping the pane, files and unsaved edits. In a shown pane with no file, Cmd+B closes the pane and returns the keyboard to the terminal. Cmd+W with the keyboard in the pane closes the pane when no file is open, otherwise the active tab; the last tab closes the pane. The Files button and Esc toggle the tree inside a pane with files; in a pane with no file they hide the pane. Enter on a file in the tree opens it and moves the keyboard into it. The viewer is optional: a Settings switch, on by default, turns off new panes. Arrows: Left in the tree (not on an open folder) goes to the file, Right in a viewed file goes to the tree. A path click shows a hidden pane and focuses it; `tarn open` leaves it hidden and never moves the keyboard. Markdown shows rendered (highlight, mermaid with a per-diagram Source toggle, Copy on code blocks, task checkboxes written back to the file) or as source in an editor (Cmd+E); Cmd+S saves, an edit marks the tab dirty. Cmd+= (also Cmd++), Cmd+- and Cmd+0 zoom the pane while it holds the keyboard; the last two and Cmd++ follow the terminal's font size keys, in Safari's steps from 50% to 300%; one zoom for every pane, kept across launches. Ghostty's tab and window keybinds that have no menu item (Cmd+1 to Cmd+9, previous and next tab, move tab, previous and next window, tab overview, maximize, decorations, background opacity; the user's own keys for them too) work while the pane holds the keyboard: the pane runs them on the focused terminal of its tab. Terminal input keys (Cmd+Left, Cmd+Backspace and the like) stay with the page. Other text files show highlighted with line numbers and edit the same way; `path:line` scrolls to the line and marks it. Markdown is rendered from vendored assets in a WKWebView. A file changed on disk is re-rendered with the scroll kept; with unsaved edits the pane shows "The agent changed this file and you have unsaved edits" with "Take the agent version" and "Keep mine".
4. Rules: no network: a `WKContentRuleList` blocks everything except `tarn-md://`, which serves bundled assets and local images of allowed folders; raw HTML inside markdown is escaped; `http(s)` links open in the system browser. Files over 5 MB or not UTF-8 get a one-line notice. The theme follows the terminal background. `tarn open` needs an absolute path, answers ok or an error and opens text files only and refuses binary files ("not a text file") and files over 5 MB ("too large"). A path click opens every file: in the viewer when it can show it, otherwise (binary, over 5 MB, `.drawio`/`.dio`, media, document and archive types) in the default app; apps, packages and executables are blocked with a toast. Ghostty's undo reopens a closed pane.

## Open and save rules

- Which text is a link is Ghostty's matcher (`src/config/url.zig`): a path with a slash (`docs/a.md`, `./a.md`, `../a.md`, `~/a.md`, `/abs/a.md`, each with optional `:line`). A bare name from `ls` is not a link (user decision 2026-10-25). `$VAR/...` is matched, not expanded. Relative paths resolve against the surface's pwd (OSC 7).
- A click on a URL, a directory or a missing file is left to Ghostty. A file the viewer cannot show (media, document, archive, `.drawio`, over 5 MB, binary) opens in the default app, except `.app`, `.pkg` and executables, which are blocked with a toast.
- A click opens a preview tab and focuses the pane. Socket `open` never takes focus: the first responder is restored; if the user types in the pane meanwhile, the open adds a pinned background tab and keeps the active one.
- Disk change: throttled 0.3 s. Clean document: reload and flash. Dirty document: a banner (Take the agent version / Keep mine), once per disk text. Deleted file: the tab keeps its text and Save writes it again.
- Save works for any text file; it re-reads the disk first and refuses to overwrite a changed file; the write is atomic, follows a symlink and keeps the mode. Ticking a task box writes the marker on its source line and needs a clean, current document.
- Close: one sheet (Save, Don't Save, Cancel) lists the dirty files of the tab group or, on quit, of all windows. Don't Save keeps the edits and lets the repeated close pass once. Closing the last tab closes the viewer and registers an undo that reopens the tabs.
- Settings > Modules > File viewer (default on). Off: no pane is drawn; tabs, layout and unsaved edits stay and return when it is on; Cmd+B and viewer split keys do nothing, path clicks go to Ghostty's opener, `tarn open` answers "the file viewer is off in Settings", the Toggle File Viewer button and menu item are hidden; closing a tab with edits still asks.
- No network: every load is blocked except `tarn-md://`; images only under the tree root or the folder of an open file; the page navigates only to its first URL. Markdown by markdown-it (html off), code by highlight.js (limit 512 KB), editor CodeMirror 6, mermaid `securityLevel: "strict"`, loaded on demand; the bundle is built by esbuild and committed, so the app build needs no node.
- Colors (T-151): the page takes the terminal theme; with `window-theme` system, light or dark the built-in palettes return.
